# Task Management App

A responsive task management app built with HTML, CSS and JavaScript.

## Features
- Personal and Work workspaces
- Create, view, edit and delete tasks
- Task priorities, statuses and due dates
- Search by title or description
- Combined status and priority filters
- Sort tasks by due date
- Recent activity showing the last five actions
- Data persistence using localStorage
- Responsive design for mobile and desktop
- Drag-and-drop task cards

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html and select "Open with Live Server".

## Data Storage
Tasks and recent activity are saved in the browser using localStorage
and remain after a page refresh.

Data is specific to the browser and site address. It does not sync
across devices, and clearing site data removes it.

## Technologies
- HTML
- CSS
- JavaScript
- Browser localStorage
